# SOFIE GT™ — Limited Edition Human
Vite + vanilla JS. No backend, no API keys.

    npm install
    npm run dev

## Videos
Put `video4.mp4`, `video7.mp4`, `video10.mp4` in `public/assets/videos/`. Placeholders swap out automatically (refresh once). `video4.mp4` is used for both the opening and chapter 04, as briefed.
